A few quick answers

Good to know.

Everything you need before getting started with Studio.exe.

Studio.exe is listed for Windows 10 and Windows 11 on x64 systems. Check the release notes for any version-specific requirements.

They are optional developer tools. The setup flow can offer them, but install only the runtimes your projects need.

Use the GitHub repository and Releases page linked above to view source, release notes and available downloads.

Choose Setup.exe for the guided installer, Setup.msi for Windows Installer deployment, Studio.exe for the standalone app, or the ZIP for a portable archive.

Get up and running

Start building in minutes.

Install Studio.exe, open a project and choose the tools you need.

01 · Install Studio

Run setup.exe for the guided installation, or use setup.msi for Windows Installer deployment. The setup offers optional Node.js 22, Python 3 and .NET 10 SDK installation.

02 · Open a project

Open an existing folder or create your project. Use the explorer to manage files and the editor to work on your code.

03 · Add language tools

Install optional language servers and debug adapters from Studio's Extensions section for richer completions and debugging.

04 · Build and explore

Use the terminal and build actions for supported projects, or switch to the 3D workspace to create and edit scenes.
